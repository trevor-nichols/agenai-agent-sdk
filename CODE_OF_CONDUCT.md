# Code of conduct

We want this project to be a useful, professional place to work together.

Be respectful and specific. Discuss code and technical decisions without attacking the people
behind them. Assume good intent, make room for different experience levels, and accept correction
gracefully. Harassment, threats, discrimination, sexualized conduct, and publishing another
person's private information are not acceptable.

Project maintainers may edit or remove comments, commits, issues, and other contributions that do
not meet these expectations. Serious or repeated violations may lead to a temporary or permanent
ban from project spaces.

Report conduct concerns privately through the repository owner's GitHub profile. Include links or
screenshots that help explain what happened. Reports will be handled as confidentially as the
situation allows.
